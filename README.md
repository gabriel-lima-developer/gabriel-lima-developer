## Projeto em destaque

### YouInControl

Projeto pessoal criado como laboratório técnico e produto em evolução, com o objetivo de aplicar conceitos modernos de desenvolvimento full stack, cloud e arquitetura.

O primeiro módulo do projeto é uma aplicação para gerenciamento de listas de compras, com frontend em React e backend em .NET.

#### Principais objetivos técnicos

* Praticar desenvolvimento full stack com .NET e React.
* Aplicar uma estrutura backend organizada e preparada para evolução.
* Utilizar Docker e PostgreSQL no ambiente de desenvolvimento.
* Publicar frontend e backend em ambiente cloud.
* Evoluir o projeto gradualmente com autenticação, separação de usuários, melhorias de produto e novos módulos.

#### Tecnologias utilizadas

* .NET
* C#
* React
* Tailwind CSS
* PostgreSQL
* Docker
* Azure
* GitHub Actions

#### Funcionalidades atuais

* Criação e gerenciamento de listas de compras.
* Cadastro de itens.
* Quantidade e unidade de medida por item.
* Separação entre itens pendentes e concluídos.
* Confirmação antes de exclusões.
* Interface responsiva e publicada.
* Integração real entre frontend e backend.

#### Próximas evoluções planejadas

* Autenticação de usuários.
* Separação de dados por conta.
* Login social.
* Melhorias nos endpoints do BFF.
* Dashboard inicial.
* PWA e notificações.
* Funcionalidades com IA para geração de listas, sugestões de itens, identificação de marcas e estimativa de valores médios.
